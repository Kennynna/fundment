# WhatsApp: ссылка с готовым сообщением

Пожелание пользователя от 7 ноября 2026: кнопки WhatsApp должны открывать чат с заранее заполненным текстом обращения, чтобы посетителю не приходилось писать его с нуля. Применять этот подход при подключении контактов в эконом- и премиум-вариантах.

## Формат из примера пользователя

```text
https://api.whatsapp.com/send/?phone=НОМЕР&text=ТЕКСТ_В_URL_КОДИРОВКЕ&type=phone_number&app_absent=0
```

Короткий официальный формат:

```text
https://wa.me/НОМЕР?text=ТЕКСТ_В_URL_КОДИРОВКЕ
```

- Номер — в международном формате, только цифры, без `+`, пробелов и скобок.
- Текст передавать через `URLSearchParams` или `encodeURIComponent`, кодируя только один раз.
- В самой ссылке разделители параметров — `&`, без обратных слешей. В строковом HTML атрибуте — `&amp;`; в JSX можно передавать готовый URL как выражение.
- Сообщение появляется в поле ввода. Посетитель может отредактировать его и самостоятельно нажимает «Отправить». Это ссылка Click to Chat, а не автоматическая отправка через Business API.

## Формирование ссылки

```ts
function createWhatsAppLink(phone: string, message: string) {
  const params = new URLSearchParams({
    phone,
    text: message,
    type: "phone_number",
    app_absent: "0",
  });
  return `https://api.whatsapp.com/send/?${params.toString()}`;
}
```

Предлагаемый текст для Фаворит-групп:

> Здравствуйте! Пишу с сайта Фаворит-групп. Хочу обсудить фундамент или дренаж для моего участка.

Для кнопки конкретной услуги можно использовать более точный текст, например: «Здравствуйте! Интересует плитный фундамент. Хочу обсудить мой проект».

## Исходный образец — не контакт Фаворит-групп

Пользователь привёл номер `79614515151` и сообщение:

> Здравствуйте! Пишу с сайта polevektor.ru — хочу проконсультироваться по оборудованию и решениям для обработки зерна.

Это образец формата ссылки. Не подключать этот номер к сайту Фаворит-групп без отдельного подтверждения, что он принадлежит компании. Не переносить в сообщение название polevektor.ru или обращение про зерно.

Контактный компонент: `components/social-contacts.tsx`. Пока настоящий номер компании не указан, сохранять `url: null`.
